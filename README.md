A premium, high-performance portfolio website built with modern web technologies. This project showcases my skills as a Full Stack Developer, highlighting my projects, certifications, and experience with a focus on 3D interactive elements and smooth animations.

## 🚀 Tech Stack

- **Frontend Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion (3D Tilt, Parallax, Transitions)
- **Icons:** Lucide React
- **Deployment:** Vercel / Netlify / Render

## ✨ Features

- **3D Interactive Cards:** Project cards featuring tilt effects and gloss/glare interactions.
- **Parallax Hero Section:** Mouse-move reactive background elements for an immersive feel.
- **Responsive Design:** Fully optimized for all devices from mobile to large desktops.
- **Performance Optimized:** Fast load times with code splitting and optimized assets.
- **Functional Contact Form:** Direct mailto integration for seamless communication.

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```

4. **Build for Production**
   ```bash
   npm run build
   ```

## 🌍 Deployment Guide

This project is optimized for deployment on **Vercel** or **Netlify**.

### Deploy on Vercel (Recommended)

1.  Push your code to a GitHub repository.
2.  Go to [Vercel](https://vercel.com) and sign in.
3.  Click **"Add New"** > **"Project"**.
4.  Import your GitHub repository.
5.  Vercel will automatically detect the **Vite** framework settings.
    *   **Build Command:** `npm run build`
    *   **Output Directory:** `dist`
6.  Click **"Deploy"**.

### Deploy on Netlify

1.  Push your code to a GitHub repository.
2.  Go to [Netlify](https://www.netlify.com) and sign in.
3.  Click **"Add new site"** > **"Import from Git"**.
4.  Connect to GitHub and select your repository.
5.  Set the build settings:
    *   **Build command:** `npm run build`
    *   **Publish directory:** `dist`
6.  Click **"Deploy site"**.
